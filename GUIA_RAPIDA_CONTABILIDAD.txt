"""
GUÍA RÁPIDA - Módulo de Contabilidad
====================================

Esta es una guía paso a paso para comenzar con el módulo de contabilidad.

PARTE 1: INSTALACIÓN Y SETUP
============================

Paso 1: Verificar Requisitos
-----------------------------
✓ Django instalado
✓ Base de datos configurada (PostgreSQL preferentemente)
✓ Al menos una empresa creada en el sistema
✓ Usuario admin/superuser creado


Paso 2: Instalación Automática (RECOMENDADO)
---------------------------------------------

python setup_contabilidad.py

Esto hará automáticamente:
  1. Verificar que todo esté listo
  2. Generar migraciones
  3. Aplicar migraciones a BD
  4. Generar datos de demostración (opcional)


Paso 3: Instalación Manual (Alternativa)
-----------------------------------------

python manage.py makemigrations apps.contabilidad
python manage.py makemigrations apps.compras apps.productos
python manage.py migrate
python manage.py generar_demo --empresa-id 1


Paso 4: Verificar
-----------------

python manage.py shell
>>> from apps.contabilidad.models import PlanCuentas
>>> PlanCuentas.objects.count()  # Debe ser > 0
24


PARTE 2: CARGA DE DATOS
=======================

Preparar Archivos Excel
------------------------

Los archivos Excel deben tener:
  - Encabezado EN LA FILA 1
  - Datos desde la FILA 2
  - Sin celdas combinadas
  - Sin fórmulas


Cargar Plan de Cuentas
----------------------

1. Preparar archivo: plan_cuentas.xlsx
   Columnas:
     A: Código (ej: 1100)
     B: Descripción (ej: Caja)
     C: Condición (deudora/acreedora)
     D: Clase (sintetica/analitica)
     E: Código Reducido (opcional)
     F: Acepta Ítem (S/N)
     G: Acepta CC (S/N)
     H: Acepta Nivel (S/N)

2. Ejecutar:
   python manage.py cargar_plan_cuentas plan_cuentas.xlsx

   Con opciones:
   python manage.py cargar_plan_cuentas plan_cuentas.xlsx --empresa-id 1 --limpiar


Cargar Proveedores
-------------------

1. Preparar: proveedores.xlsx
   Columnas:
     A: Nombre (ej: Distribuidora ABC)
     B: RUC (ej: 80123456)
     C: Email (ej: info@abc.py)
     D: Teléfono (ej: 0971123456)
     E: Dirección (ej: Calle X, Ciudad)
     F: Email SET (opcional)
     G: Emite Electrónica (S/N)
     H: Timbrado Número (opcional)
     I: Timbrado Vencimiento (opcional)
     J: Código Cuenta Contable (ej: 2110)

2. Ejecutar:
   python manage.py importar_proveedores proveedores.xlsx

   Con cuenta por defecto:
   python manage.py importar_proveedores proveedores.xlsx --cuenta-contable 2110


Cargar Productos
-----------------

1. Preparar: productos.xlsx
   Columnas:
     A: Código (ej: PROD001)
     B: Descripción (ej: Producto ABC)
     C: Categoría (ej: Electrónica)
     D: Precio (ej: 1500.50)
     E: Stock Mínimo (ej: 10)
     F: Stock Máximo (ej: 100)
     G: Código Cuenta (ej: 1210)
     H: Unidad Medida (ej: UN - Unidad)

2. Ejecutar:
   python manage.py importar_productos productos.xlsx


Cargar Cotizaciones
--------------------

1. Preparar: cotizaciones.xlsx
   Columnas:
     A: Fecha (YYYY-MM-DD, ej: 2025-01-15)
     B: Moneda Origen (USD, EUR, PYG, ARS, BRL)
     C: Moneda Destino (USD, EUR, PYG, ARS, BRL)
     D: Tasa (ej: 6600.50)
     E: Fuente (ej: BCP, Manual)

2. Ejecutar:
   python manage.py cargar_cotizaciones cotizaciones.xlsx


Validar Cotizaciones Faltantes
-------------------------------

Si falta algún tipo de cambio:

python manage.py validar_cotizaciones --dias 30 --crear-faltantes

Esto verifica los últimos 30 días y crea automáticamente:
  - USD/PYG con tasa aproximada 6600
  - USD/ARS con tasa aproximada 830
  - EUR/PYG con tasa aproximada 7200


PARTE 3: OPERACIÓN DIARIA
==========================

Crear Compra (Auto-genera Asiento)
-----------------------------------

1. Crear Compra en Admin o vía API
2. Asignar Proveedor (DEBE tener cuenta_contable asignada)
3. Agregar Productos (DEBEN tener cuenta_contable asignada)
4. Cambiar estado a 'recepcionada'

✅ Se genera automáticamente un ASIENTO CONTABLE
   - DEBE: Cuenta del producto × cantidad
   - HABER: Cuenta del proveedor × total


Verificar Asientos
------------------

Admin:
  http://localhost:8000/admin/contabilidad/asiento/

API:
  GET http://localhost:8000/api/v1/contabilidad/asientos/
  GET http://localhost:8000/api/v1/contabilidad/asientos/{id}/


Registrar Asiento
-----------------

Un asiento comienza en estado 'borrador'.

Para registrarlo:

Opción 1 - Admin:
  1. Ir a Contabilidad > Asientos
  2. Abrir asiento
  3. Clickear botón "Registrar"
  4. Se cambia a estado "registrado"

Opción 2 - API:
  POST /api/v1/contabilidad/asientos/{id}/registrar/

✅ Una vez registrado, aparece en reportes


Revertir Asiento
-----------------

Si necesitar revertir un asiento registrado:

Opción 1 - Admin:
  1. Abrir el asiento
  2. Clickear "Reversar"
  3. Se crea automáticamente un asiento inverso

Opción 2 - API:
  POST /api/v1/contabilidad/asientos/{id}/reversar/

=================

Salida en pantalla:

    --hasta 2025-01-31 \

  - Concepto

  - Haber
  - Saldo


Libro Diario
------------

Todos los movimientos en orden cronológico:

python manage.py reportes diario --empresa-id 1 --salida diario.csv

Salida:

  - Debe
  - Haber
  - Concepto


PARTE 5: CONSULTAS VÍA API
==========================

Listar Plan de Cuentas
----------------------

GET /api/v1/contabilidad/plan-cuentas/

Parámetros:
  - search=1100          # Buscar por código
  - page=1               # Paginación
  - page_size=50         # Items por página


Filtrar por Condición
---------------------

GET /api/v1/contabilidad/plan-cuentas/por-condicion/?condicion=deudora


Ver Estructura Jerárquica
--------------------------

GET /api/v1/contabilidad/plan-cuentas/arbol/

Retorna árbol completo de cuentas.


Listar Asientos
---------------

GET /api/v1/contabilidad/asientos/

Parámetros:
  - estado=registrado    # Filtrar por estado
  - tipo_asiento=compra  # Filtrar por tipo
  - desde=2025-01-01     # Filtro fecha


Obtener Balance General
-----------------------

GET /api/v1/contabilidad/asientos/balance_general/

Retorna:
{
  "activos": 500000.00,
  "pasivos": -200000.00,
  "patrimonio": -300000.00,
  "detalles": [...]
}


Cotizaciones del Día
--------------------

GET /api/v1/contabilidad/cotizaciones-diarias/hoy/

Retorna tipos de cambio actuales.


Cotizaciones por Rango
----------------------

GET /api/v1/contabilidad/cotizaciones-diarias/rango/?desde=2025-01-01&hasta=2025-01-31


PARTE 6: TROUBLESHOOTING
========================

"ValueError: cuenta_contable"
-----------------------------

Significa que un Proveedor o Producto no tiene cuenta asignada.

Solución:
  1. Ir a Admin > Compras > Proveedor
  2. Editar el proveedor
  3. Asignar una cuenta en "Cuenta Contable"
  4. Guardar

O vía comando:
  python manage.py importar_proveedores data.xlsx --cuenta-contable 2110


"No existe cotización para hoy"
--------------------------------

Significa que falta el tipo de cambio.

Solución:
  python manage.py validar_cotizaciones --crear-faltantes

O cargar manualmente:
  python manage.py cargar_cotizaciones cotizaciones.xlsx


"Asiento no se genera automáticamente"
--------------------------------------

Verificar:
  1. Proveedor tiene cuenta_contable
  2. Cada Producto tiene cuenta_contable
  3. Compra cambió estado a 'recepcionada'
  4. Revisar logs: django.log

Debug:
  python manage.py shell
  >>> from apps.compras.models import Compra
  >>> c = Compra.objects.get(id=123)
  >>> c.proveedor.cuenta_contable
  # Debe mostrar una cuenta, no None


"Debe != Haber"
---------------

Un asiento debe estar balanceado.

Verificar:
  1. Ver detalles del asiento
  2. Sumar todos los DEBE
  3. Sumar todos los HABER
  4. Deben ser iguales

Debug:
  python manage.py shell
  >>> from apps.contabilidad.models import Asiento
  >>> a = Asiento.objects.get(id=123)
  >>> a.validate_balance()
  # Lanza ValidationError si está desbalanceado
